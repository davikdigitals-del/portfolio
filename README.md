# Portfolio Website - Ajibola Gbenga Joseph

A modern, professional portfolio website for a website designer and developer, built with Next.js 14, TypeScript, and Tailwind CSS.

## ✨ Features

- 🎨 Modern, responsive design
- ⚡ Fast performance with Next.js 14
- 📱 Mobile-first approach
- 🎯 SEO optimized
- 💼 Professional service showcase
- 📊 Case studies section
- 📮 Contact form
- 🎭 Smooth animations
- 🌐 Ready for deployment

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel (recommended)

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📄 Pages

- **Home** (`/`) - Hero section with services preview
- **About** (`/about`) - About me, skills, and technologies
- **Services** (`/services`) - Detailed service offerings
- **Case Studies** (`/case-studies`) - Portfolio projects
- **Contact** (`/contact`) - Contact form and information

## 🎨 Customization

### Colors
Edit the color scheme in `tailwind.config.ts`:
```typescript
colors: {
  primary: { ... },
  dark: { ... }
}
```

### Content
Update content directly in the page and component files.

### Images
Add your images to the `public/` directory and update the references.

## 🚀 Deployment

### Vercel (Recommended)
1. Push your code to GitHub
2. Import project on [Vercel](https://vercel.com)
3. Deploy with one click

### Other Platforms
```bash
npm run build
npm start
```
